# Expense Tracker & Money Planner App

A cross-platform mobile application built using Flutter and Dart to help users automate recurring expenses, set budget limits, and visualize spending patterns in real-time.

## Key Features
- **Visual Analytics:** Interactive bar and pie charts powered by `FL Chart` for real-time expenditure tracking.
- **Budget Planning & Reminders:** Custom budget limits, automated recurring transactions, and bill due-date notifications.
- **Offline Storage & Security:** Fast, local SQLite database storage using `SQFlite` ensuring data privacy.
- **Dynamic UX:** Modular architecture with light/dark theme management, search/filter capabilities, and custom categories.

## Tech Stack
- **Framework:** Flutter (Cross-platform)
- **Programming Language:** Dart
- **State Management:** GetX
- **Database:** SQFlite (SQLite)
- **Data Visualization:** FL Chart
- **Local Storage:** Shared Preferences
